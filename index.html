How do I get a file from Google Maps?

Google Maps stores places in two different systems with different export options:

Easy Google My Maps (custom maps)

Maps you created at mymaps.google.com have direct KML export.

  1. Open the map at mymaps.google.com
  2. Click the ⋮ menu next to the map title
  3. Choose "Export to KML/KMZ" → download → drop here
More work Google Maps Saved Lists

Lists in the regular Maps app ("Want to go", "Favorites", custom lists) have no direct export. You need Google Takeout — easier on a desktop than on a phone.

  1. Go to takeout.google.com
  2. Pick only "Maps (your places)" and request the export
  3. Wait for the email (minutes to hours) → download the .zip
  4. Drop the whole .zip here — we'll find every list inside
📱 On mobile

The Takeout flow is desktop-friendlier. On a phone: request the export from your computer, then email yourself the resulting .zip and download it on your phone, or wait until you're at a desktop. Single individual places can also be added one at a time via the "From links" tab.

If you can copy a KML file's contents (e.g. from a text editor or webview), paste it here as a fallback when the file picker doesn't cooperate.
Each URL must point to one place. Short links (maps.app.goo.gl) work for individual place shares but not saved-list shares.

Google Maps API Key
Optional. With a key, place search uses Google Places (much better for Japanese restaurants & shops). Without one, search falls back to free OpenStreetMap sources.
How to get a key:
  1. Go to console.cloud.google.com
  2. Create a new project (or use existing)
  3. In APIs & Services → Library, enable ALL THREE: Maps JavaScript API, Places API (legacy — NOT "New"), and Places API (New).
  4. In Credentials → Create credentials → API key. Copy the key.
  5. For safety, restrict the key to your IP or websites in the API key settings.
Your key is saved only in this browser (localStorage). It is never sent anywhere except directly to Google's servers.
